# MindPalace · 记忆宫殿

> 「你知道的，我把它叫做我的记忆宫殿。」
>
> 夏洛克·福尔摩斯在脑子里修了一座宫殿。每一条线索、每一张面孔、每一件别人不会多看一眼的细节，
> 都被他放进宫殿的某个房间里；要用的时候，他只要在宫殿里走一圈，就能把它们取出来。
>
> 现在，你也可以拥有自己的记忆宫殿。

**MindPalace 把你脑子里的知识，变成一间可以走进去的图书馆。**

穹顶下的圆形阅览室：两侧书架沿墙而立，大厅中央立着几根书柱，
一条条银丝从书柱那头牵过来，穿过整个大厅，落在一本本书上 ——那是「你学过的东西」和「你做过的事」之间的连线。

里面已经装好了一整套**夏洛克·福尔摩斯主题**的示例：**5 面书架、122 本知识笔记，外加 4 根书柱、81 篇案例手记**。


## 三步用起来

**1. 解压**

把 zip 解压到任意位置。

**2. 双击 `MindPalace.exe`**

会弹出一个窗口，图书馆就在里面。

- **第一次打开需要联网**（要下载几个画图的小组件，之后会缓存住）
- 不需要安装任何东西，不需要注册，不需要填任何配置

**3. 关掉窗口就是退出**

窗口右上角一关，程序就结束了。

## 1. 键鼠操作

| 操作 | 效果 |
| --- | --- |
| `W` `A` `S` `D` | 前进 / 左移 / 后退 / 右移 |
| 鼠标拖拽 | 转动视角 |
| 滚轮 | 拉近拉远；或点击书柱上的铭牌，选中一根书柱后，滚轮将控制转动那根书柱，方便看它背面的书 |
| 空格 | 一步回到全景 |
| 点击一本书 | 打开它，读到整篇笔记 |
| 点击书架 / 书柱的铭牌 | 视角飞过去 |
| 点击大厅中央的矮凳 | 回到图书馆中心 —— 走丢了就点它 |

**认路靠两条**：左边那一栏是可以点的目录；顶上那一栏可以搜索（回车直接跳过去）。

## 2. 手势操作

不碰键鼠也能逛。这是最效仿夏洛克记忆宫殿的地方！点界面**最底下那条状态带**上的 **✋ 手势操作**，会请求授权使用摄像头。
摄像头的小预览窗在右下角，可移动，可收起。

| 手势 | 效果 |
| --- | --- |
| 食指单指 | 出现光圈跟着指尖；悬停一会儿就锁定目标 |
| 食指 + 拇指捏合 | 打开 / 确认（锁定后光圈变绿） |
| 张开手掌 | 左右移动 = 转向，上下移动 = 俯仰 |
| 双手分开 / 合起 | 放大 / 缩小 |
| 握拳 | 画面静止，什么也不做 |
| 食指向上/下指 | 在打开阅读面板后控制内容上下滚动 |

> 手势吃光。光线足一点、手离摄像头半米到一米、背后别太乱，最稳。

## 换成自己的笔记

里面那 203 篇示例是为了更好的初次体验。换成自己的东西很简单：

### 两个文件夹

```text
knowledge/     ← 你「想记住」的东西，会变成书架上的书
problems/      ← 你「用过、做过」的事，会变成大厅里的书柱
```

**knowledge 里放「我懂了什么」，problems 里放「我在哪用上了」。**

### 文件夹就是建筑

`knowledge/` 里：

| 文件夹层级 | 变成什么 |
| --- | --- |
| 第一层文件夹 | 一面书架 |
| 第二层文件夹 | 书架的一层 |
| 更深的文件夹 | 层里面的书盒（点开能看到里面的书） |
| `.md` 文件 | 一本书，**文件名就是书脊上的书名** |

`problems/` 里：

| 文件夹层级 | 变成什么 |
| --- | --- |
| 第一层文件夹 | 一根书柱 |
| 更深的文件夹 | 书柱上的书盒 |
| `.md` 文件 | 书柱上的一本书 |
| 空文件夹 | 不生成任何东西 |

举个例：

```text
knowledge/
├── 心理学/                  ← 一面书架
│   ├── 认知偏差/             ← 书架的一层
│   │   └── 锚定效应.md        ← 一本书
│   └── 动机/
│       └── 损失厌恶.md
└── 生活/
    └── 咖啡萃取参数.md        ← 直接放在书架下，也算一层

problems/
├── 工作复盘/                 ← 一根书柱
│   └── 2026Q1-定价谈判失误.md
└── 读书实践/
    └── 用锚定效应分析一次报价.md
```

随手扔在 `knowledge/` 根目录、没归类的笔记不会被丢掉，会集中到一面叫「未分类」的书架上。

### 加完怎么生效

回到界面按 `Ctrl + R` 刷新，新的书就摆上架了。需要AI分析内容时，点一下顶部的**重新整理书架**，这会调用大模型来分析标签和建立银丝。如果你有自己的 API Key，在 `.env` 里填上，分析会更准确。**（项目中放的为示例，修改后请将命名从.env.example改为.env）**




## 书脊的颜色是什么意思

书脊的颜色深浅，是这本书**被应用记录引用过多少次**：

- **暗红** → 被引用最多
- 依次往浅走：土黄 → 深绿 → 深青 → 深蓝 → **黑紫**（引用最少）
- **中性灰** → 记下来了，但一次都没用上

不用手动维护，程序自己算。
