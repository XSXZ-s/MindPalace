# 我们两个都不说话的那些晚上

## 标签
221B的日常, 沉默, 晚上

## 涉及知识块
沉默的用法, 那间客厅的规矩, 深夜回来的人

---
*S. H. —— 有人以为住在一起总要说话。我们有一半的晚上是不说话的。约翰刚搬进来的时候，这一半他过不惯。*

## 记录
我们两个人的晚上，多数时候是各干各的。

## 那种晚上是什么样
- 我坐在靠窗那张椅子上，膝盖上摊着报纸，半天翻一页
- 约翰在另一头写东西，写完一张就搁在一边
- 火是一直烧着的。**谁起身添煤，另一个人不用抬头**
- 中间会有很长的一段，屋里只有火的声音和我翻纸的声音

**一句话都没有。但那不是冷场——这一点约翰比我更早说出来。**

## 约翰后来怎么分辨这两种沉默
不说话这件事分两种，这一点约翰是慢慢学会的：

|                    | 那是什么样的                                                 |
| ------------------ | ------------------------------------------------------------ |
| **我忙的时候**     | 约翰不来打扰。我那时候在脑子里走，走了很远，叫我也听不见     |
| **我没在忙的时候** | 这种沉默是另一个东西——**我不走神，我只是不说。**这种时候约翰说话，我会接 |

**约翰分辨这两种沉默的办法是看手：**我忙的时候手在动（翻纸、擦琴、敲桌沿）；我没在忙的时候两只手是静的。

## 那一次约翰什么都没说
有一晚我办完一件案子回来，坐下，没有说话。约翰给我倒了一杯水，放在我手边，然后回去写他的东西。**约翰没有问我案子的事——是不是知道那天不该问，我没问过他。**

**那一晚我们一共说了两个字：约翰说"水"，我说"嗯"。**

第二天早上我把那杯水喝完了，杯子放回了原位。

## 复盘
- 约翰刚搬进来的时候受不了这种安静，总觉得应该找话说。**后来他发现，在这栋楼里，找话说反而是不礼貌的**
- 这种安静有一样好处：**它让真正想说的那句留出位置。**我这一生跟约翰讲过的几件要紧的事，都是在这样安静的晚上忽然开口的
- 约翰在连载里几乎没有写过这些晚上。**因为写不出来——但那是约翰住在这栋楼里最好的一部分时间**

## 两个人的说法
**我的版本：**

「一屋子两个人都不说话，并不代表这两个人没事。**有时候是因为不必说。**」

**约翰后来跟我说的：**

「他这句话是我们住在一起第三年，他忽然对着墙说出来的。我当时没接。**因为那一句已经够了。**」
